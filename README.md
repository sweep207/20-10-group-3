# Website chúc mừng 20/10 — Nhóm 3

Website tĩnh dành cho lời chúc Ngày Phụ nữ Việt Nam 20/10, tối ưu cho điện thoại và có hiệu ứng phong bì, gõ chữ, trái tim cùng khu vực gửi lời chúc cộng đồng.

## Cấu trúc

- `index.html` — cấu trúc trang và các vùng nội dung.
- `styles.css` — toàn bộ giao diện, hiệu ứng và bố cục responsive.
- `script.js` — hiệu ứng tương tác và tích hợp Supabase.
- `SUPABASE_SETUP.md` — hướng dẫn cấu hình bảng, RLS và duyệt lời chúc.

## Chạy thử

Có thể mở `index.html` bằng trình duyệt hoặc dùng máy chủ tĩnh cục bộ. Một số trình duyệt hạn chế âm thanh tự phát; hãy tương tác với trang trước khi phát nhạc.

## Triển khai GitHub Pages

Trong **Settings → Pages**, chọn nhánh `master` và thư mục `/(root)` (hoặc giữ nguyên nguồn Pages đang hoạt động nếu đã cấu hình). Sau khi cập nhật, theo dõi tab **Actions** để biết lần deploy thành công.

## Lời chúc cộng đồng

Các lời chúc mới được gửi với trạng thái `pending`; chỉ bản ghi `approved` mới hiển thị công khai. Xem `SUPABASE_SETUP.md` để biết cách quản lý duyệt bài an toàn.
